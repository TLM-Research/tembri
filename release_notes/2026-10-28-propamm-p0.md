# PropAMM P0 foundation

**Date:** 28 October 2026

Tembri now includes an initial, evidence-led PropAMM measurement pipeline for
Ethereum execution data.

## Added

- Typed rows for projected PropAMM logs, calls, updates, fills, fill pairs, and
  block/pool and builder-signal summaries.
- Reviewed-event decoding that matches an exact contract address and log topic;
  ambiguous overlapping fill rules fail closed.
- Decoding of Priority Update Registry signed-batch calldata. The decoder
  captures the reviewed target and maker-selected `updateTimestamp`, and emits
  updates only for explicitly allow-listed targets.
- Deterministic same-block, same-pool update-to-fill pairing in EVM transaction
  order.
- Per-fill transaction-index and cumulative-gas gap measurements.
- Explicit `propamm_fill_without_update` output for fills without an earlier
  same-block update.
- `tembri propamm-decode` and `tembri propamm-pair` commands for the reviewed
  evidence and pairing stages.

## Validation

- Unit coverage includes exact-rule matching, signed-batch decoding, target
  allow-listing, timestamp retention, update/fill pairing, unmatched fills,
  multiple fills between updates, and aggregation.
- The decode-to-pair command handoff has been exercised with a fixture.
- `cargo test --workspace` and `cargo clippy --workspace -- -D warnings` pass.

## Boundaries

This release proves on-chain receipt order for reviewed evidence. It does not
prove that an update was the maker's newest off-chain quote, when a builder
received it, or whether a route was public or private. Venue coverage is
deliberately limited to reviewed rules and targets; generic swaps, transfers,
and unreviewed contracts are not inferred to be PropAMM activity.
